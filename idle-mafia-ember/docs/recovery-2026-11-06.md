## Local development

Run from `idle-mafia-ember/` with Git on PATH and full history available:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest tests -q
node --test tests/preview-model.test.mjs
python tools/build_ui_prototype.py --check
python tools/build_release_manifest.py --preflight
node tools/check_native_audit.mjs
node tools/build_preview.mjs
```

Release building intentionally compares working-tree bytes with committed blobs.
On Windows use an LF checkout (`git -c core.autocrlf=false clone ...`) for release
assembly; changing line endings is not a reason to weaken hash validation.
Historical entry tests require full Git history and use no network.
