# Native Shop quote source boundary (offline)

The saved 0.26.530 client calls `Util.shopStock(GameData, ServerClock.now())` and calculates a five-minute slot. Its cash purchase path sends `BuyShopItem(itemId, nil, finalCashPrice)`. The displayed cash price starts with `Util.shopPrice(offer, slot)` and then applies `TerritoryBonusRules.shopPrice` with the current territory, Global sale and decree inputs. The saved source lives in ignored `.private/place-2026-10-22/Util-*.lua` and `ShopTab-*.lua`. These are client-side call shapes, not server validation or a confirmed purchase outcome.

`ShopQuoteProducer.derive` accepts an injected `shopQuoteSource` only when its `release` and `catalogKey` match the loaded Shop catalog. `source:Stock(serverNow)` must return a dense boolean stock map for the reviewed cash offers, the exact next restock time, and the slot. `source:CashQuote(itemId, slot, raw)` must return the final discounted integer cash price using current state. The producer rejects partial stock, mismatched rotation, quotes outside the reviewed ceiling, and the last four seconds of a slot. It copies only stock and quote scalars into an account/revision-bound proof. `AutomationRuntime` clears any snapshot-supplied proof before trying this source. Without the source, Shop cannot propose a buy; a concurrently enabled Bank deposit reserves all cash for the unquoted Shop purchase.
