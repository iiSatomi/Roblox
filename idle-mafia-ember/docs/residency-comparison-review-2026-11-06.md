# Selected residence comparison — November 6, 2026

Residency now compares the selected district's native resident contribution and
rent with the current native residence. It does not rank every district or assign
a common value to unrelated bonus kinds. The reviewed client sources do not
expose the server's complete holder/resident composition formula, so no future
combined bonus total is fabricated.

An active replacement must keep the same bonus kind. Higher actual resident share
without higher rent can qualify below the current native bonus cap. Lower rent
can qualify without losing resident share. An already capped bonus cannot justify
another move by itself. Equal/worse terms, conflicting or missing current facts,
different bonus kinds, and a higher-share/higher-rent tradeoff remain unavailable.
First admission requires a current effective bonus table and room below the cap,
as well as the selected minimum share, maximum rent and explicit attempt limit.
Replacement and owner-request permissions remain independent requirements.

The comparison uses the exact native `derived.residency` kind/share/rent/active
facts, `derived.territoryBonuses`, and reviewed `TerritoryBonusRules` caps. It does
not add the residence to nominal district stats or treat all Family holdings as
active. The compared facts are captured in the proposal and checked again before
dispatch. Confirmation additionally requires the selected native lease kind and
at least the originally quoted resident share, along with the existing lease,
rent, newer Sync and terminal-reply checks. There is no automatic rollback.

The current observed free 6.5% property-income residence dominates a selected 4%
offer charging 1% rent. The regression originally accepted that loss and now
refuses it. Other regressions cover same-kind improvement, capped gains, rent
reduction, cross-kind and unknown facts, changed comparison custody and incorrect
confirmed bonus identity. They execute actual Luau modules offline. This review
does not claim a live residence move was performed.
